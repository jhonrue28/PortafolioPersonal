Sobre mí

Soy desarrollador de software junior, interesado en crear soluciones tecnológicas que respondan a necesidades reales. Me gusta aprender nuevas tecnologías, resolver problemas y convertir ideas en proyectos funcionales. Tengo experiencia académica y práctica trabajando con tecnologías como Java, Python, JavaScript, HTML, CSS y MySQL, además de herramientas como Git y n8n para el desarrollo y la automatización de procesos. Me caracterizo por ser una persona autodidacta, analítica y adaptable, con disposición para aprender, trabajar en equipo y asumir nuevos retos. Mi objetivo es seguir fortaleciendo mis habilidades y aportar al desarrollo de proyectos que generen valor.

Proyectos

CrediYa

Sistema de consola en Java para la operación de cartera de CrediYa S.A.S. Permite registrar empleados y clientes, asociar un préstamo a un cliente y a un empleado, anotar pagos y consultar préstamos activos, vencidos y clientes en mora.

Qué aprendí

Aprendí a separar el sistema en clases, servicios y repositorios, y a guardar la misma información en archivos o en MySQL mediante JDBC. También practiqué el cálculo de saldos y los reportes de préstamos activos, vencidos y clientes en mora.

Ver repositorio en GitHub

Campuslands Ops

Aplicación web de operaciones del campus Campuslands, desarrollada en equipo. Reúne el plano de las salas, las reservas con horario y capacidad, el inventario de computadores y periféricos, y el registro de incidentes, que la persona operadora confirma antes de guardar.

Qué aprendí

Al participar en este proyecto de equipo, practiqué cómo una interfaz web consulta una API y cómo el servidor valida las reservas, el inventario y los incidentes antes de guardarlos.

Ver repositorio en GitHub

Proyecto Python

Programa de consola en Python del repositorio de Jessica Urrego y Jhonatan Rueda. Ofrece menús de camper, trainer y coordinador para la inscripción, la consulta de ruta y notas, el seguimiento de campers y la administración de trainers, salones y rutas en archivos JSON.

Qué aprendí

Aprendí a construir menús de consola para cada perfil y a leer y actualizar listas y diccionarios de campers, trainers, salones y rutas en archivos JSON.

Ver repositorio en GitHub

Portal API Colombia

Portal web informativo que consulta la API pública de API Colombia. Desde el inicio se puede ver información general del país, un listado de presidentes y el listado de departamentos.

Qué aprendí

Aprendí a pedir datos a la API con fetch, a ordenar y recorrer la respuesta, y a mostrar el país, los presidentes y los departamentos directamente en la página.

Ver repositorio en GitHub
